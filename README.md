# Saint George and the Dragon

A kid-friendly browser adventure: play as Saint George, explore the kingdom, and face the dragon.

**Play:** https://zbitt106-cfs.github.io/Saint-George/

## Controls

- **Arrows / WASD** — move
- **Space / E** — talk and attack
- Hold Shift / X (controller X/Square or LB/RB): block with shield
- **Q** — quest log
- Xbox and PlayStation controllers are supported
